# VIBEBIOS 🖥️

[🇷🇺 Русский](README_ru.md) | [🇬🇧 English](README.md)

**VIBEBIOS** — это кастомная 32-битная графическая прошивка (ROM BIOS), написанная с нуля на C и Assembly для архитектуры x86 (специально под эмулятор QEMU). 

В отличие от стандартных загрузчиков (которые грузятся в `0x7C00`), этот проект является **настоящим BIOS**. Он компилируется в бинарный ROM-файл размером 128 КБ, мапится в самый конец 4 ГБ адресного пространства материнской платы и перехватывает управление прямо с вектора сброса процессора (`0xFFFFFFF0`).

## 🌟 Фичи

* **Мгновенный 32-битный режим:** Никакого долгого сидения в 16-битном реальном режиме. BIOS настраивает GDT и прыгает в Protected Mode в первые же микросекунды старта.
* **Полноценный C Runtime:** Динамическое перемещение секции `.data` в RAM и зануление `.bss` для полноценной работы глобальных и статических переменных в C.
* **Поддержка ACPI и SMBIOS:** Генерация валидных таблиц ACPI (RSDP, RSDT) и SMBIOS в памяти (в стиле Coreboot) для современных ОС.
* **Энергонезависимая память (CMOS):** Сохранение настроек BIOS (шрифты, переключатели IDE/ACPI) в энергонезависимую память RTC CMOS.
* **Дерево устройств PCI:** Сканирование шины PCI и отрисовка аппаратного дерева прямо в интерфейсе BIOS Setup.
* **High-Res Графика (800x600):** Работа с шиной PCI для настройки видеокарты и включения Linear Frame Buffer (LFB) с поддержкой 32-битного ARGB цвета.
* **Собственный GUI:** Интегрированная графическая утилита настройки (по F2) с поддержкой мыши, всплывающими окнами и динамическими шрифтами (Fixedsys, Sun).
* **Загрузочные устройства:** Аппаратные драйверы для загрузки с жесткого диска (ATA PIO), дискет (Floppy) и по сети (PXE).
* **Загрузка классических ОС:** Валидация сигнатуры `0x55 0xAA`, создание заглушки 16-битной таблицы прерываний (IVT), отключение конфликтующей периферии PS/2 и безопасный возврат в Real Mode для загрузки систем вроде GRUB и Ubuntu.

## 🛠️ Зависимости

Для сборки проекта под Linux потребуются:
* `gcc` (с поддержкой `-m32`)
* `nasm` (Ассемблер)
* `binutils` (для утилит `ld` и `objcopy`)
* `qemu-system-x86_64` или `qemu-system-i386` (Эмулятор)
* `make`

## 🚀 Быстрый старт

1. Склонируйте репозиторий.
2. В терминале выполните команду для компиляции и запуска:
   ```bash
   make run
   ```
3. Проект скомпилирует ядро BIOS (`bios.bin`), соберет тестовую ОС (`os.bin`) и запустит QEMU.
4. Для очистки директории от скомпилированных файлов используйте:
   ```bash
   make clean
   ```

## 📂 Структура проекта

* `boot.asm` — Стартовый ассемблерный код, Вектор Сброса процессора, GDT, инициализация C Runtime и переход в 32 бита.
* `bios.c` — Ядро BIOS на C (Инициализация VGA, PCI, GUI, меню и логика загрузки).
* `drv_*.c` — Драйверы оборудования (ATA, Floppy, Клавиатура, PXE, PCI).
* `acpi.c` / `smbios.c` — Генерация системных таблиц.
* `linker.ld` — Скрипт линковщика, формирующий правильную архитектуру 128 KB ROM и секции для RAM.
* `os.asm` — Минимальная тестовая ОС, демонстрирующая перехват управления у BIOS.
* `Makefile` — Скрипт автоматизации сборки.

## ⚠️ Дисклеймер

VibeBIOS — это экспериментальный проект, во многом вдохновленный такими гигантами как SeaBIOS, Insyde и Coreboot. Несмотря на то, что он реализует множество стандартных функций BIOS (ACPI, CMOS, PCI, возврат в Real-Mode), он может не иметь полной совместимости со старыми узкоспециализированными системами.
